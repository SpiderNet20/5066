# دليل نظام إدارة المحتوى (CMS) والتوافق مع الاستضافة - العنكبوت للمعلومات

تم تطوير هذا النظام لتمكين إدارة ونشر وتعديل المقالات لموقع **العنكبوت للمعلومات** (`https://www.information-net.com`) بشكل دائم وتلقائي دون الحاجة لتعديل الكود أو إعادة بناء المشروع في كل مقال جديد.

---

## 1. الوصول إلى لوحة التحكم (Admin Panel)

- **الرابط:** `https://www.information-net.com/admin` (أو `http://localhost:3000/admin` أثناء التطوير).
- **اسم المستخدم الافتراضي:** `admin`
- **كلمة المرور الافتراضية:** `SpiderNet@2026!`
- **تغيير كلمة المرور:** يمكنك تغيير كلمة المرور واسم المستخدم في أي وقت من تبويب **"الإعدادات"** داخل لوحة التحكم.

---

## 2. ميزات لوحة التحكم

1. **إدارة المقالات:**
   - تصفح المقالات المنشورة والمسودات مع عداد فوري.
   - البحث السريع بالعنوان، الرابط، أو الوسوم.
   - فلترة المقالات حسب القسم أو الحالة (منشور / مسودة).
   - نشر فوري، تحويل إلى مسودة، أو حذف مقال بعد تأكيد الحذف عبر نافذة مخصصة.

2. **نموذج إضافة وتعديل المقال المتكامل:**
   - **عنوان المقال:** حقل مخصص مع توليد تلقائي للرابط الدائم (Slug).
   - **الرابط الدائم (Slug):** يدعم التخصيص اليدوي ويمنع التكرار تلقائياً.
   - **التصنيف الرئيسي:** اختيار القسم من بين الأقسام المعتمدة:
     - `AI` (الذكاء الاصطناعي)
     - `Games` (الألعاب)
     - `Software` (البرامج)
     - `Downloads` (تطبيقات وتنزيلات)
     - `Business` (المال والأعمال)
     - `Blog` (المدونة والشروحات)
     - `Education` (مقالات تعليمية)
   - **الوسوم (Tags):** إضافة وسوم متعددة وتنسيقها على شكل بطاقات (Chips).
   - **محرر المحتوى المزدوج:**
     - **محرر مرئي منسق:** أزرار سريعة لإدراج عناوين رئيسية H2 وعناوين فرعية H3، قوائم نقطية ورقمية، اقتباسات، كتل برمجية، وروابط، وملاحظات زرقاء وصفراء منسقة.
     - **كود HTML مباشر:** للتحكم الكامل في كود الصفحة وتنسيقات الجداول والعناصر الخاصة.
   - **الصورة البارزة (Thumbnail) وAlt Text:**
     - رفع الصور مباشرة من الجهاز إلى الخادم عبر واجهة API محمية وتوليد مسار دائم `/uploads/image.png`.
     - دعم الروابط الخارجية للصور المباشرة مثل Blogger.
     - النص البديل (Alt) لتحسين سيو الصور في بحث Google Images.
   - **إعدادات السيو المتقدمة (SEO):**
     - عنوان SEO مخصص ووصف Meta Description مع شريط تقدم لعدد الأحرف الموصى به.
     - معاينة فورية لشكل النتيجة في محرك بحث جوجل (Google SERP Snippet).
     - مفتاح حالة الفهرسة (Robots Meta): التبديل بين `index, follow` و `noindex, nofollow`.
   - **معاينة المقال الحية:**
     - زر "معاينة المقال" يفتح المقال بنفس قالب وعناصر موقع العنكبوت للمعلومات الحقيقية (بما فيها جدول المحتويات التلقائي TOC والشريط الجانبي) للتأكد من تنسيقه قبل نشره للزوار.

---

## 3. آلية التخزين الدائم (Persistent Storage Architecture)

- **الملف الدائم للخادم:** يتم حفظ المقالات في `data/posts.json`.
- **النسخ الاحتياطي التلقائي:** يتم إنشاء نسخة احتياطية مشفرة بالوقت والتاريخ في `data/backups/posts-backup-*.json` مع كل عملية حفظ أو تعديل أو نشر، مع الاحتفاظ بأحدث 15 نسخة تلقائياً.
- **التوافق التام مع المقالات القديمة:** تم استيراد وترحيل كافة مقالات `INITIAL_POSTS` تلقائياً مع الحفاظ على معرّفاتها وتواريخها وتصنيفاتها ووسومها، وتظل `INITIAL_POSTS` كطبقة أمان احتياطية في حال تعذر الاتصال بالخادم.
- **تصدير النسخة الاحتياطية:** يمكن للمسؤول بضغطة زر تنزيل ملف JSON كامل لجميع مقالات الموقع من تبويب الإعدادات.

---

## 4. نظام خرائط الموقع (Sitemaps) و SEO التلقائي

عند نشر مقال جديد:
1. **خرائط السايت ماب الديناميكية:**
   - خريطة الموقع الرئيسية: `/sitemap.xml`
   - خريطة المدونة: `/sitemap-blog.xml`
   - فهرس الخرائط: `/sitemap_index.xml`
   تقوم الخرائط بالاستعلام المباشر من قاعدة بيانات الخادم، وتُدرج المقالات المنشورة فوراً مع تاريخ آخر تعديل وأولوية السيو `priority`، وتستبعد المسودات والمقالات التي تم ضبطها على `noindex`.
2. **الحقن البرمجي على جانب الخادم (SSR SEO):**
   - يوفر `server.ts` حقناً للوسوم الوصفية لـ Googlebot ومحركات البحث ومواقع التواصل (`og:title`, `og:image`, `canonical`, وSchema.org JSON-LD) بشكل لحظي من قاعدة البيانات.
3. **ترويسات كاش Cloudflare:**
   - تم ضبط `Cache-Control: public, max-age=0, must-revalidate` على واجهات API للمقالات، و`max-age=300, stale-while-revalidate=60` على الخرائط، لمنع تقديم نسخ مخبأة قديمة للزوار عند إضافة مقال جديد.

## 5. توافق Cloudflare والاستضافة

1. **الوضع الحالي (Node.js / Express Server):**
   - يعمل التطبيق بخادم Express مدمج مع Vite عبر `tsx server.ts`.
   - هذا التكوين متوافق مع كافة خدمات الاستضافة السحابية مثل VPS, Cloud Run, Render, Railway, DigitalOcean, أو استضافة خلف Cloudflare CDN / Proxy.
2. **الترحيل إلى Cloudflare D1 (اختياري للمستقبل):**
   - تم تضمين ملف `d1-schema.sql` في جذر المشروع.
   - إذا رغبت في نقل قاعدة البيانات بالكامل إلى Cloudflare D1 بدون خادم Node.js، يمكنك تنفيذ:
     ```bash
     wrangler d1 create information-net-db
     wrangler d1 execute information-net-db --file=d1-schema.sql
     ```
